# 小小便便民工具箱小程序

微信原生小程序，支持公积金贷、商贷、组合贷款，还款方式支持等额本息与等额本金，并在结果页用饼图展示本金与利息占比。

## 功能

- 贷款类型：公积金贷 / 商贷 / 组合贷款
- 还款方式：等额本息 / 等额本金
- 输出：首月/每月还款、贷款总额、支付利息、还款总额
- 还款计划：按月展示本金、利息、剩余本金
- 饼图：还款本金与利息比例

## 使用

1. 安装并打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入本项目目录
3. AppID 可先使用测试号 / 游客模式（`project.config.json` 中当前为 `touristappid`）
4. 编译运行即可

## 目录

```
├── app.js / app.json / app.wxss
├── pages
│   ├── index    # 参数填写
│   └── result   # 结果、饼图、还款计划
└── utils
    ├── mortgage.js  # 计算逻辑
    └── pie.js       # 饼图绘制
```

## 说明

- 利率、年限可自行调整，默认值为常见参考值，不代表最新政策利率
- 组合贷按商贷与公积金分别计算后合并月供与还款计划
